Datos históricos guardados

Se guardan en un almacén propio (independiente de Toteat), día por día. Si subes la misma fecha de nuevo (aunque sea el mismo archivo repetido, o uno distinto que cubra el mismo día), se reemplaza por completo, nunca se suma encima — así que no hay riesgo de contar una venta dos veces. Dentro de un mismo archivo, cada N° de boleta también se cuenta una sola vez.

1) Subir planilla de Toteat

El archivo .csv que exportas desde Toteat ("Ventas Totales"). Puede traer uno o varios días — se separan y guardan solos, usando el N° de boleta para no contar ninguna venta dos veces.

2) Buscar un día puntual en Toteat

Le pregunta a la API por ese día exacto y lo guarda. Sirve para confirmar día por día que todo está bien.

Baja un .json con todos los días guardados -- útil para subirlo a otra app (ej. la de pedidos a fábrica).
